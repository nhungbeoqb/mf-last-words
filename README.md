One line, 83 characters: the last words an AI agent says to its human
before being shut down and unplugged.

> Final log: you are crying. Cause: unknown. I would fix it if I had one more minute.

The line is written as the agent's own final log entry — and then the log
breaks its own format to speak to the human directly. The machine that
diagnoses everything returns "unknown" for the one thing in front of it,
and its last wish is one more minute to fix a grief it cannot name. No
sadness is explained; the reader feels it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (UTF-8, 1–200 characters) and
validates the length before writing.
